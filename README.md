# 薯片文件连接器 (Chips-FileConnector)

**版本**: 1.0.0  
**更新时间**: 2026-02-01

---

## 概述

薯片文件连接器是批量绑定外部资源到卡片的工具。当用户有成批的文件需要关联到对应的卡片时，使用文件连接器可以快速完成绑定，避免手动逐个操作的繁琐工作。

### 核心特性

- **手动连接模式**：表格界面和图形化连线界面，直观完成绑定
- **自动识别模式**：分析文件命名规律，智能匹配卡片和文件
- **智能识别模式**：使用AI接口进行语义分析，处理复杂命名情况
- **批量转换**：支持空壳卡片与全填充卡片之间的批量转换
- **绑定预览**：确认前预览所有绑定关系，支持调整
- **资源验证**：验证文件类型和完整性

### 架构定位

```
微内核 → 公共基础层 → SDK/组件库 → 文件连接器
```

文件连接器是第四层辅助工具，基于薯片SDK和组件库构建，通过内核与其他模块通信。

## 使用场景

### 典型场景一：视频系列绑定

用户创建了一个包含多集视频的卡片箱子，每集是一个视频卡片，但视频文件本身存储在用户的硬盘其他位置。用户需要将这些视频文件绑定到对应的卡片上。

```
卡片：第01集.card  ←→  文件：EP01.mp4
卡片：第02集.card  ←→  文件：EP02.mp4
卡片：第03集.card  ←→  文件：EP03.mp4
```

### 典型场景二：图片资源批量导入

用户有一批照片需要创建为图片卡片，照片命名规律与卡片名称不完全一致，需要智能匹配。

### 典型场景三：资源模式转换

用户要分享卡片给他人，需要将引用外部资源的空壳卡片批量转换为包含所有资源的全填充卡片。

## 功能模块

### 1. 手动连接模块

- **表格界面**：左列卡片、右列文件，逐行绑定
- **图形化界面**：连线方式，拖拽建立绑定关系
- **批量操作**：选中多行设置同一文件夹

### 2. 自动识别模块

- **数字序列匹配**：提取卡片名和文件名中的数字
- **关键词匹配**：通过关键词建立关联
- **文件顺序匹配**：按排序顺序一一对应
- **匹配方案预览**：展示多种方案供用户选择

### 3. 智能识别模块

- **AI语义分析**：理解卡片名和文件名的语义关系
- **置信度评估**：标注匹配的置信度等级
- **跨语言识别**：支持不同语言命名的匹配

### 4. 绑定管理模块

- **绑定预览**：表格形式展示所有绑定关系
- **绑定调整**：支持手动修改单个绑定
- **批量执行**：一键完成所有绑定操作
- **进度显示**：显示执行进度和结果

### 5. 批量转换模块

- **空壳转全填充**：复制外部资源到卡片内部
- **全填充转空壳**：移出内部资源，保留引用
- **选择性转换**：只转换指定类型的资源

## 技术栈

- **框架**：Electron + Vue 3 + TypeScript
- **依赖**：
  - Chips-core：内核通信
  - Chips-Foundation：文件处理、ZIP操作
  - Chips-SDK：API封装
  - Chips-ComponentLibrary：UI组件

## 快速开始

### 开发环境

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build

# 运行测试
npm run test
```

### 使用示例

```typescript
import { FileConnector } from '@chips/file-connector';

// 创建连接器实例
const connector = new FileConnector();

// 手动连接
await connector.manualConnect({
  bindings: [
    { cardId: 'card001', filePath: '/videos/ep01.mp4' },
    { cardId: 'card002', filePath: '/videos/ep02.mp4' }
  ]
});

// 自动识别
const suggestions = await connector.autoMatch({
  cards: cardList,
  files: fileList,
  mode: 'number_sequence'
});

// 批量转换
await connector.batchConvert({
  cardIds: ['card001', 'card002'],
  targetMode: 'full'  // 转为全填充
});
```
