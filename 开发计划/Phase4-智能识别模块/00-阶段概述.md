### P4-T04: 实现AI降级机制

**描述**: AI服务不可用时降级到自动匹配

**具体工作**:
1. 在SmartMatcher中添加 `fallbackMatch()` 方法
2. 检测AI服务可用性
3. 服务不可用时自动使用SchemeGenerator
4. 提示用户当前使用的是降级模式
5. 实现优雅降级（不中断用户操作）

**实现代码**:
```typescript
class SmartMatcher {
  private schemeGenerator: SchemeGenerator;
  
  async match(cards: CardInfo[], files: FileInfo[]): Promise<SmartMatchResult> {
    try {
      // 尝试AI匹配
      const response = await this.aiClient.smartMatch(
        this.prepareRequest(cards, files)
      );
      return this.parseResponse(response);
    } catch (error) {
      // 降级到自动匹配
      console.warn('AI service unavailable, falling back to auto match');
      return this.fallbackMatch(cards, files);
    }
  }
  
  private async fallbackMatch(
    cards: CardInfo[],
    files: FileInfo[]
  ): Promise<SmartMatchResult> {
    const schemes = this.schemeGenerator.generateAll(cards, files);
    const best = schemes[0];
    
    return {
      bindings: best.bindings.map(b => ({
        ...b,
        confidence: best.confidence,
        reason: `使用${best.mode}模式自动匹配（AI服务不可用）`
      })),
      unmatchedCards: best.unmatchedCards,
      unmatchedFiles: best.unmatchedFiles,
      metadata: {
        processingTime: 0,
        modelVersion: 'fallback'
      }
    };
  }
}
```

**验收标准**:
- [ ] AI不可用时自动降级
