### P2-T12: 实现useManualConnect组合式函数

**描述**: 手动连接的核心逻辑

**具体工作**:
1. 创建 `src/renderer/composables/useManualConnect.ts`
2. 实现绑定管理逻辑
3. 实现数据验证逻辑
4. 实现与Store的交互
5. 导出供视图使用的方法和状态

**接口定义**:
```typescript
export function useManualConnect() {
  // 状态
  const bindings: Ref<BindingItem[]>;
  const mode: Ref<'table' | 'graph'>;
  
  // 方法
  function addBinding(cardId: string, filePath: string): void;
  function removeBinding(cardId: string): void;
  function updateBinding(cardId: string, filePath: string): void;
  function clearBindings(): void;
  function validateBindings(): ValidationResult;
  
  return { bindings, mode, addBinding, removeBinding, updateBinding, clearBindings, validateBindings };
}
```
