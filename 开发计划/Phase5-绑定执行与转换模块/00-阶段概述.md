### P5-T02: 实现BindingExecutor绑定执行器

**描述**: 执行批量绑定操作

**具体工作**:
1. 创建 `src/core/executors/BindingExecutor.ts`
2. 实现单个绑定执行
3. 实现批量绑定执行
4. 实现进度回调
5. 实现错误处理策略（skip/retry/abort）
6. 实现重试逻辑
7. 实现执行报告生成

**类接口**:
```typescript
class BindingExecutor extends EventEmitter {
  constructor(sdk: ChipsSDK, logger?: Logger);
  
  async execute(
    bindings: BindingItem[],
    options?: ExecuteOptions
  ): Promise<ExecuteResult>;
  
  async executeSingle(binding: BindingItem): Promise<SingleExecuteResult>;
  
  getProgress(): ExecutionProgress;
  cancel(): void;
  isExecuting(): boolean;
}

interface ExecuteOptions {
  copyToInternal?: boolean;
  errorStrategy?: 'skip' | 'retry' | 'abort';
  maxRetries?: number;
  concurrency?: number;
  onProgress?: (progress: ExecutionProgress) => void;
  onError?: (error: ExecutionError) => ErrorAction;
}
```

**执行流程**:
```
开始执行
    │
    ▼
验证绑定 ──失败──► 报告错误
    │
   成功
    │
    ▼
读取卡片配置
    │
    ▼
更新资源路径
    │
    ▼
保存卡片配置
    │
    ▼
[可选] 复制文件到卡片内部
    │
    ▼
更新进度
    │
    ▼
下一个 / 完成
```

**验收标准**:

- [ ] 批量执行正确
- [ ] 进度回调正确
