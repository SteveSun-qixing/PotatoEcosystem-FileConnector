## 3. 任务详情

### P3-T01: 实现NumberSequenceMatcher数字匹配器

**描述**: 实现基于数字序列的匹配算法

**具体工作**:
1. 创建 `src/core/matchers/NumberSequenceMatcher.ts`
2. 实现 `extractNumbers()` 方法 - 从字符串提取数字
3. 实现 `selectNumber()` 方法 - 选择用于匹配的数字
4. 实现 `match()` 方法 - 执行匹配
5. 实现 `resolveConflicts()` 方法 - 处理冲突
6. 实现 `isApplicable()` 方法 - 检查是否适用
7. 实现置信度计算

**类接口**:
```typescript
class NumberSequenceMatcher implements IMatcher {
  readonly name = 'NumberSequenceMatcher';
  readonly mode: MatchMode = 'number_sequence';
  
  extractNumbers(text: string): NumberInfo[];
  selectNumber(numbers: NumberInfo[], position: NumberPosition): NumberInfo | null;
  match(cards: CardInfo[], files: FileInfo[], options?: MatchOptions): MatchScheme;
  isApplicable(cards: CardInfo[], files: FileInfo[]): boolean;
  resolveConflicts(conflicts: MatchConflict[], strategy: ConflictStrategy): BindingItem[];
}
```

**验收标准**:
- [ ] 正确提取数字（包括前导零处理）
- [ ] 正确匹配卡片和文件
- [ ] 正确处理冲突
- [ ] 置信度计算合理

**相关文档**: 技术文档/03-匹配算法设计.md

3. 实现 `jaccardSimilarity()` 方法 - Jaccard相似度

}
```

**验收标准**:
- [ ] 分词正确（中英文混合）

**接口定义**:

export function useAutoMatch() {
  const schemes: Ref<MatchScheme[]>;
  const selectedIndex: Ref<number>;
  const loading: Ref<boolean>;
  
  async function generateSchemes(cards: CardInfo[], files: FileInfo[]): Promise<void>;
  function selectScheme(index: number): void;
  function applyScheme(): BindingItem[];
  function getSelectedScheme(): MatchScheme | null;
  
  return { schemes, selectedIndex, loading, generateSchemes, selectScheme, applyScheme, getSelectedScheme };
}
```
