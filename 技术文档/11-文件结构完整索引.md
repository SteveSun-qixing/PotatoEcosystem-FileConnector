## 2. 核心文件说明

### 2.1 匹配引擎文件

**`src/core/matching/MatchingEngine.ts`**
- 匹配引擎主类
- 算法调度
- 结果合并

**`src/core/matching/NumberMatcher.ts`**
- 数字识别算法
- 中文数字解析
- 序号提取

**`src/core/matching/AIMatcher.ts`**
- AI智能匹配
- 语义分析
- 相似度计算

### 2.2 绑定执行文件

**`src/core/binding/BindingExecutor.ts`**
- 绑定执行协调
- 事务管理
- 错误回滚

**`src/core/binding/ConfigUpdater.ts`**
- 配置文件更新
- YAML解析和写入
- 配置验证

## 3. 文件组织规范

### 3.1 命名规范
- **类文件**：大驼峰命名
- **工具文件**：小驼峰命名
- **类型文件**：小写

### 3.2 导入路径
```typescript
import { MatchingEngine } from '@/core/matching/MatchingEngine'
import { FileUtils } from '@/utils/fileUtils'
```
