# 文件连接器 - 接口完整索引

## 1. 核心接口

### 1.1 匹配器接口

#### IMatcher
```typescript
interface IMatcher {
  analyze(cards: Card[], files: File[]): Promise<MatchingAnalysis>
  match(cards: Card[], files: File[]): Promise<Binding[]>
}
```

### 1.2 匹配结果接口

```typescript
interface Binding {
  cardId: string
  filePath: string
  confidence: number
  algorithm: string
}

interface MatchingAnalysis {
  totalCards: number
  totalFiles: number
  patterns: Pattern[]
  suggestions: Algorithm[]
  confidence: number
}

interface ExecutionResult {
  success: boolean
  processed: number
  failed: number
  errors: Error[]
  duration: number
}
```

### 1.3 配置接口

```typescript
interface BindingOptions {
  mode: 'update-config' | 'copy-files' | 'move-files'
  backup: boolean
  overwrite: boolean
  verifyAfter: boolean
}

interface AIOptions {
  model: string
  temperature: number
  maxTokens: number
}

interface CustomRule {
  name: string
  pattern: RegExp
  mapper: (match: RegExpMatchArray) => string
}
```

## 2. 数据接口

```typescript
interface Card {
  id: string
  name: string
  config: CardConfig
  resources?: Resource[]
}

interface File {
  path: string
  name: string
  size: number
  type: string
  extension: string
}

interface Pattern {
  type: 'number' | 'keyword' | 'date' | 'custom'
  confidence: number
  examples: string[]
}
```

## 3. 事件接口

```typescript
interface IProgressCallback {
  (progress: number, message?: string): void
}

interface IMatchCompleteCallback {
  (bindings: Binding[]): void
}

interface IErrorCallback {
  (error: Error): void
}
```

## 4. 总结

文件连接器定义了完整的接口体系：
- **核心接口**：匹配器、匹配结果、配置
- **数据接口**：卡片、文件、模式
- **事件接口**：进度、完成、错误回调

所有接口都使用TypeScript定义。
