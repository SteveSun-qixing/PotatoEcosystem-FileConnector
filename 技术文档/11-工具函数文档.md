### 1.2 getFileType

根据文件名获取文件类型。

```typescript

```

#### 参数

#### 返回值

| 类型 | 说明 |


| 类型 | 扩展名 |
|------|-------|

| other | 其他所有扩展名 |

#### 示例

```typescript

getFileType('movie.mp4');    // 'video'
getFileType('song.mp3');     // 'audio'
getFileType('photo.jpg');    // 'image'
getFileType('readme.txt');   // 'document'
getFileType('unknown.xyz');  // 'other'
```

### 2.3 jaccardSimilarity

计算两个集合的 Jaccard 相似度。

```typescript
function jaccardSimilarity(set1: Set<string>, set2: Set<string>): number
```

#### 参数

| 参数名 | 类型 | 说明 |
|-------|------|------|
| set1 | `Set<string>` | 集合1 |
| set2 | `Set<string>` | 集合2 |

#### 返回值

| 类型 | 说明 |
|------|------|
| `number` | 相似度（0-1） |

#### 计算公式

```
Jaccard = |A ∩ B| / |A ∪ B|
```

#### 示例

```typescript
import { jaccardSimilarity } from '@/utils/match';

const set1 = new Set(['a', 'b', 'c']);
const set2 = new Set(['b', 'c', 'd']);

jaccardSimilarity(set1, set2);  // 0.5 (交集2个，并集4个)
jaccardSimilarity(set1, set1);  // 1.0
jaccardSimilarity(new Set(), new Set());  // 0
```

### 2.4 editDistance

计算两个字符串的编辑距离（Levenshtein 距离）。

```typescript
function editDistance(s1: string, s2: string): number
```

#### 参数

| 参数名 | 类型 | 说明 |
|-------|------|------|
| s1 | `string` | 字符串1 |
| s2 | `string` | 字符串2 |

#### 返回值

| 类型 | 说明 |
|------|------|
| `number` | 编辑距离（最少需要的插入、删除、替换操作数） |

#### 示例

```typescript

editDistance('kitten', 'sitting');  // 3
editDistance('hello', 'hello');     // 0
editDistance('', 'abc');            // 3
editDistance('abc', '');            // 3
```

### 2.5 editDistanceSimilarity

计算基于编辑距离的相似度。

```typescript
function editDistanceSimilarity(s1: string, s2: string): number
```

#### 参数

| 参数名 | 类型 | 说明 |
|-------|------|------|
| s1 | `string` | 字符串1 |
| s2 | `string` | 字符串2 |

#### 返回值

| 类型 | 说明 |
|------|------|
| `number` | 相似度（0-1），1表示完全相同 |

#### 计算公式

```
similarity = 1 - editDistance / max(len(s1), len(s2))
```

#### 示例

```typescript
import { editDistanceSimilarity } from '@/utils/match';

editDistanceSimilarity('hello', 'hello');   // 1.0
editDistanceSimilarity('hello', 'hallo');   // 0.8
editDistanceSimilarity('abc', 'xyz');       // 0.0
editDistanceSimilarity('', '');             // 1.0
```

### 4.2 retry

带重试的异步操作。

```typescript
function retry<T>(
  operation: () => Promise<T>,
  maxAttempts?: number,
  delayMs?: number,
  backoff?: boolean
): Promise<T>
```

#### 参数

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| operation | `() => Promise<T>` | - | 异步操作函数 |
| maxAttempts | `number` | `3` | 最大尝试次数 |
| delayMs | `number` | `1000` | 重试间隔（毫秒） |
| backoff | `boolean` | `true` | 是否使用指数退避 |

#### 返回值

| 类型 | 说明 |
|------|------|
| `Promise<T>` | 操作成功的结果 |

#### 异常

如果所有尝试都失败，会抛出最后一次尝试的错误。

#### 示例

```typescript
import { retry } from '@/utils/async';

// 带重试的 API 调用
const result = await retry(
  () => fetchAPI('/data'),
  3,      // 最多尝试3次
  1000,   // 初始间隔1秒
  true    // 使用指数退避（1s, 2s, 4s）
);
```

|------|------|

