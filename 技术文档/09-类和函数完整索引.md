class MatchingEngine {

## 4. 类型定义

```typescript
interface IMatcher {
  analyze(cards: Card[], files: File[]): Promise<MatchingAnalysis>
  match(cards: Card[], files: File[]): Promise<Binding[]>
}

interface Card {
  id: string
  name: string
  config: CardConfig
}

interface File {
  path: string
  name: string
  size: number
}

interface Binding {
  cardId: string
  filePath: string
  confidence: number
  algorithm: string
}

type MatchingAlgorithm = 'number' | 'keyword' | 'order' | 'ai' | 'custom'
```

## 5. 总结

文件连接器包含完整的类和函数体系：
- **匹配引擎**：MatchingEngine

- **绑定执行**：BindingExecutor、ConfigUpdater

所有类和函数都提供TypeScript类型定义。
