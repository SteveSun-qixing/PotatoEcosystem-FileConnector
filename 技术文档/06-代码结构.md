## 2. 模块职责

### 2.1 主进程 (main/)

| 模块 | 职责 |
|------|------|
| index.ts | 应用入口，初始化 |
| window.ts | 窗口创建和管理 |
| ipc/ | 主进程IPC处理 |

### 2.2 渲染进程 (renderer/)

| 模块 | 职责 |
|------|------|
| views/ | 页面级组件 |
| components/ | 可复用UI组件 |
| composables/ | 组合式逻辑函数 |
| stores/ | 全局状态管理 |
| router/ | 路由配置 |

### 2.3 核心逻辑 (core/)

| 模块 | 职责 |
|------|------|
| connector/ | 连接器主类和配置 |
| matchers/ | 各种匹配算法实现 |
| executors/ | 绑定执行和模式转换 |
| validators/ | 数据验证 |

### 2.4 适配器 (adapters/)

| 模块 | 职责 |
|------|------|
| CardAdapter | 封装SDK卡片操作 |
| ResourceAdapter | 封装SDK资源操作 |
| FileAdapter | 封装SDK文件操作 |
| AIServiceClient | AI服务调用 |

## 5. 编码规范

### 5.1 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 文件名 | PascalCase (类) / camelCase (其他) | `FileConnector.ts`, `utils.ts` |
| 类名 | PascalCase | `FileConnector`, `CardAdapter` |
| 函数名 | camelCase | `loadCards`, `executeBinding` |
| 常量 | UPPER_SNAKE_CASE | `FILE_TYPE_MAP`, `DEFAULT_CONFIG` |
| 类型/接口 | PascalCase | `CardInfo`, `BindingItem` |

### 5.2 文件组织

- 每个类一个文件
- 相关类型定义放在 `types/` 目录
- 工具函数按功能分文件放在 `utils/` 目录
- 组件按功能分目录

### 5.3 导入顺序

```typescript
// 1. Node/Electron内置模块
import { app } from 'electron';

// 2. 第三方库
import { defineStore } from 'pinia';

// 3. 内部模块（按层级）
import { FileConnector } from '@/core';
import { CardAdapter } from '@/adapters';
import { FileUtils } from '@/utils';
import type { CardInfo } from '@/types';

// 4. 相对路径导入
import { helper } from './helper';
```
