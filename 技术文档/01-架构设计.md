## 1. 总体架构

### 1.1 架构概述

文件连接器采用分层架构设计，遵循薯片生态的架构原则：

1. **表现层（Presentation Layer）** - 用户界面
2. **业务逻辑层（Business Logic Layer）** - 核心功能
3. **数据访问层（Data Access Layer）** - SDK/API调用
4. **基础设施层（Infrastructure Layer）** - 工具和配置

### 1.2 架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                         表现层                                   │
├───────────────┬───────────────┬───────────────┬─────────────────┤
│  表格连接界面  │  图形连接界面  │  方案选择界面  │   结果报告界面  │
├───────────────┴───────────────┴───────────────┴─────────────────┤
│                        业务逻辑层                                │
├───────────────┬───────────────┬───────────────┬─────────────────┤
│  手动连接器    │  自动匹配器    │   智能匹配器   │   绑定执行器    │
├───────────────┼───────────────┼───────────────┼─────────────────┤
```

## 2. 核心模块

### 2.1 手动连接模块（ManualConnector）

**职责**：
- 管理表格界面的绑定操作
- 管理图形化界面的连线操作
- 处理拖拽操作
- 维护当前绑定状态

**主要类**：
```typescript
class ManualConnector {
  // 表格模式
  tableBindings: Map<string, BindingItem>;
  
  // 图形模式
  graphBindings: Map<string, BindingItem>;
  graphLayout: GraphLayout;
  
  // 操作方法
  addBinding(cardId: string, filePath: string): void;
  removeBinding(cardId: string): void;
  updateBinding(cardId: string, filePath: string): void;
  getBindings(): BindingItem[];
  
  // 图形操作
  createConnection(cardId: string, filePath: string): void;
  removeConnection(connectionId: string): void;
  autoArrange(): void;
}
```

### 2.2 自动匹配模块（AutoMatcher）

**职责**：
- 实现数字序列匹配算法
- 实现关键词匹配算法
- 实现文件顺序匹配算法
- 生成和评估匹配方案

**主要类**：
```typescript
class AutoMatcher {
  // 匹配算法
  numberSequenceMatch(cards: CardInfo[], files: FileInfo[]): MatchScheme;
  keywordMatch(cards: CardInfo[], files: FileInfo[]): MatchScheme;
  fileOrderMatch(cards: CardInfo[], files: FileInfo[]): MatchScheme;
  
  // 综合匹配
  generateAllSchemes(cards: CardInfo[], files: FileInfo[]): MatchScheme[];
  evaluateScheme(scheme: MatchScheme): number;
  selectBestScheme(schemes: MatchScheme[]): MatchScheme;
}
```

### 2.3 智能匹配模块（SmartMatcher）

**职责**：
- 准备AI接口请求数据
- 调用AI服务
- 解析AI响应
- 处理置信度分级

**主要类**：
```typescript
class SmartMatcher {
  // AI服务客户端
  private aiClient: AIServiceClient;
  
  // 匹配方法
  async match(cards: CardInfo[], files: FileInfo[]): Promise<SmartMatchResult>;
  
  // 辅助方法
  prepareRequest(cards: CardInfo[], files: FileInfo[]): AIMatchRequest;
  parseResponse(response: AIMatchResponse): SmartMatchResult;
  classifyConfidence(matches: MatchItem[]): ClassifiedMatches;
}
```

### 2.4 绑定执行模块（BindingExecutor）

**职责**：
- 执行绑定操作
- 管理执行进度
- 处理执行错误
- 生成执行报告

**主要类**：
```typescript
class BindingExecutor {
  // 执行状态
  private progress: ExecutionProgress;
  private results: ExecutionResult[];
  
  // 执行方法
  async execute(bindings: BindingItem[], options: ExecuteOptions): Promise<ExecuteResult>;
  
  // 单个绑定执行
  async executeSingle(binding: BindingItem): Promise<SingleResult>;
  
  // 错误处理
  handleError(error: Error, binding: BindingItem): 'skip' | 'retry' | 'abort';
  
  // 进度管理
  updateProgress(current: number, total: number): void;
  getProgress(): ExecutionProgress;
}
```

### 2.5 模式转换模块（ModeConverter）

**职责**：
- 检测卡片当前资源模式
- 执行空壳→全填充转换
- 执行全填充→空壳转换
- 管理转换进度

**主要类**：
```typescript

}
```

## 6. 错误处理策略

### 6.1 错误分类

| 错误类型 | 处理策略 | 用户提示 |
|---------|---------|---------|
| 输入验证错误 | 阻止操作 | 表单提示 |
| 文件访问错误 | 跳过/重试 | 弹窗确认 |
| 网络错误 | 重试/降级 | Toast提示 |
| 系统错误 | 终止操作 | 错误对话框 |

### 6.2 错误恢复

```typescript
class ErrorRecovery {
  // 重试逻辑
  async retry<T>(
    operation: () => Promise<T>,
    maxAttempts: number = 3,
    delay: number = 1000
  ): Promise<T> {
    let lastError: Error;
    
    for (let i = 0; i < maxAttempts; i++) {
      try {
        return await operation();
      } catch (error) {
        lastError = error;
        if (i < maxAttempts - 1) {
          await this.wait(delay * Math.pow(2, i));
        }
      }
    }
    
    throw lastError;
  }
  
  // 降级逻辑
  async withFallback<T>(
    primary: () => Promise<T>,
    fallback: () => Promise<T>
  ): Promise<T> {
    try {
      return await primary();
    } catch (error) {
      console.warn('Primary failed, using fallback:', error);
      return await fallback();
    }
  }
}
```

### 7.3 并发控制

```typescript
class ConcurrencyController {
  private queue: Promise<void>[] = [];
  private maxConcurrent = 5;
  
  async add<T>(task: () => Promise<T>): Promise<T> {
    // 控制并发数量
    while (this.queue.length >= this.maxConcurrent) {
      await Promise.race(this.queue);
    }
    
    const promise = task();
    this.queue.push(promise as any);
    
    return promise;
  }
}
```

## 8. 安全考虑

### 8.1 路径安全

- 验证文件路径，防止路径遍历攻击
- 只允许访问用户授权的目录
- 文件操作遵循操作系统权限

### 8.2 数据安全

- 不修改原始资源文件（除非用户选择复制）
- 操作前预览，操作后可撤销
- 敏感信息（如AI服务令牌）不记录日志
