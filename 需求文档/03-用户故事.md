## 1. 用户角色定义

### 1.1 主要用户角色

| 角色 | 描述 | 典型场景 |
|------|------|---------|
| 视频收藏者 | 收集整理视频资源的用户 | 将下载的视频关联到已创建的卡片 |
| 图片整理者 | 整理大量图片的用户 | 批量将照片绑定到图片卡片 |
| 内容创作者 | 制作分享内容的用户 | 准备分享前转换资源模式 |
| 资料管理者 | 管理文档资料的用户 | 整理文档并关联到对应卡片 |

## 2. 用户故事

### 2.1 视频系列绑定

**用户故事 US-001**

> 作为一个**视频收藏者**，我想要**批量将下载的视频文件绑定到对应的视频卡片**，以便**在查看器中直接播放视频**。

**验收标准**：
1. 可以选择一个包含视频卡片的箱子
2. 可以选择一个包含视频文件的文件夹
3. 系统能自动识别集数对应关系
4. 可以预览绑定结果
5. 执行后视频卡片能正常播放

**场景描述**：

```
背景：
  小明下载了一部动漫的全部24集视频
  他已经在箱子中创建了24个视频卡片（命名为"第01集"到"第24集"）
  视频文件存放在下载文件夹中（命名为"[字幕组]动漫名_EP01.mp4"等）

当：
  小明打开文件连接器
  选择动漫箱子中的所有视频卡片
  选择下载文件夹中的所有视频文件
  点击"自动识别"

那么：
  系统应该识别出数字匹配规律
  显示"第01集 ↔ EP01.mp4"的匹配预览
  小明确认后执行绑定
  所有卡片都能正常播放对应的视频
```

**优先级**: P0  
**估计工作量**: 8小时

### 2.2 图片批量导入

**用户故事 US-002**

> 作为一个**图片整理者**，我想要**将旅行照片批量关联到已创建的图片卡片**，以便**方便管理和查看这些照片**。

**验收标准**：
1. 支持选择多张图片
2. 支持拖拽图片到界面
3. 可以手动建立绑定关系
4. 支持预览图片
5. 绑定后图片卡片能正常显示

**场景描述**：

```
背景：
  小红有100张旅行照片
  她已经创建了100个图片卡片，按日期和地点命名
  照片文件名是相机自动生成的（IMG_0001.jpg等）

当：
  小红打开文件连接器的图形化界面
  将照片拖入文件区域
  照片和卡片的名称没有明显规律

那么：
  小红使用手动连线方式
  逐个建立照片和卡片的对应关系
  可以预览照片确认是否正确
  完成后所有图片卡片显示对应照片
```

**优先级**: P0  
**估计工作量**: 6小时

### 2.3 跨语言智能匹配

**用户故事 US-003**

> 作为一个**视频收藏者**，我想要**将日文命名的视频文件绑定到中文命名的卡片**，以便**即使命名语言不同也能正确匹配**。

**验收标准**：
1. 支持跨语言语义分析
2. AI能理解不同语言表达的相同含义
3. 显示匹配置信度
4. 低置信度匹配可手动确认

**场景描述**：

```
背景：
  小明的卡片命名为"孤独摇滚 第一集"到"第十二集"
  下载的视频文件命名为"ぼっち・ざ・ろっく! 01話.mp4"等日文

当：
  小明选择智能识别模式
  系统调用AI分析卡片名和文件名

那么：
  AI理解"孤独摇滚"和"ぼっち・ざ・ろっく"是同一作品
  AI匹配"第一集"和"01話"
  显示匹配结果和置信度
  小明确认后完成绑定
```

**优先级**: P1  
**估计工作量**: 12小时

### 2.4 资源模式转换

  小李打开文件连接器
  选择"批量转换"功能
  选择所有教程卡片
  点击"转为全填充"

那么：
  系统显示需要复制的资源总大小
  小李确认后开始转换
  显示转换进度
  完成后卡片包含所有资源
  分享给朋友后可以直接使用
```

**优先级**: P0  
**估计工作量**: 6小时

### 2.5 字幕文件关联

  - 电影名.chs.srt（简体中文）

  - 电影名.eng.srt（英文）

当：
  小明使用文件连接器
  选择电影卡片和所有字幕文件
  选择"绑定字幕"模式

那么：
  系统自动识别字幕语言
  将三个字幕都关联到同一个卡片
  播放时可以切换字幕
```

**估计工作量**: 4小时

### 2.6 绑定关系调整

**用户故事 US-006**

> 作为一个**用户**，我想要**在自动匹配后手动调整个别绑定关系**，以便**修正自动匹配的错误**。

**验收标准**：
1. 预览界面支持单个修改
2. 可以删除某个绑定
3. 可以重新选择文件
4. 修改后实时更新预览

**场景描述**：

```
背景：
  系统自动匹配了20个绑定关系
  其中第15个匹配错了（把SP绑定到了正片）

当：
  用户在预览界面发现错误
  点击第15行的"修改"按钮
  重新选择正确的文件

那么：
  该行更新为新的绑定
  其他绑定保持不变
  可以继续执行绑定
```

### 2.7 部分资源转换

**用户故事 US-007**

> 作为一个**用户**，我想要**只转换卡片中的部分资源类型**，以便**只打包必要的资源，控制文件大小**。

**验收标准**：
1. 可以选择要转换的资源类型
2. 支持按大小筛选资源
3. 预览转换后的文件大小
4. 未转换的资源保持外部引用

**场景描述**：

```
背景：
  用户的卡片包含视频（1GB）和封面图片（100KB）
  用户只想把封面打包进去，视频保持外部引用

当：
  用户选择"选择性转换"
  只勾选"图片"类型
  或设置"只转换小于10MB的资源"

那么：
  只有封面图片被复制到卡片内部
  视频保持外部引用
  卡片大小只增加100KB
```

**优先级**: P2  
**估计工作量**: 4小时

### 2.8 错误恢复

**用户故事 US-008**

> 作为一个**用户**，我想要**在绑定执行失败时能看到详细原因并选择处理方式**，以便**解决问题后继续完成绑定**。

**验收标准**：
1. 单个失败不影响其他绑定
2. 显示失败原因
3. 可以选择跳过、重试或取消
4. 最终显示完整的执行报告

**场景描述**：

```
背景：
  用户执行100个绑定
  其中第50个文件被其他程序占用，无法读取

当：
  绑定执行到第50个时失败

那么：
  显示错误信息："文件被占用"
  提供选项：[跳过] [重试] [全部取消]
  用户选择跳过后继续执行剩余的
  最终显示："成功99个，失败1个"
```

**优先级**: P0  
**估计工作量**: 4小时

## 4. 异常场景

### 4.1 文件不存在

**场景**: 用户选择的文件在执行前被删除或移动
**处理**: 显示错误提示，允许重新选择或跳过

### 4.2 卡片被锁定

**场景**: 卡片正在被编辑引擎打开
**处理**: 提示用户关闭编辑引擎或稍后重试

### 4.3 磁盘空间不足

**场景**: 转换为全填充时磁盘空间不足
**处理**: 提前检测并警告，不开始执行

### 4.4 网络中断

**场景**: 智能识别过程中网络中断
**处理**: 提示网络错误，建议使用自动识别模式

### 4.5 大量文件处理

**场景**: 用户选择了1000+个文件
**处理**: 显示进度条，支持后台执行，允许取消
