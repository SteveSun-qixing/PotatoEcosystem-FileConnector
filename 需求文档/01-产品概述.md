# 文件连接器 - 产品概述

**版本**: 1.0.0  
**更新时间**: 2026-02-01

---

## 1. 产品定位

### 1.1 核心定位

薯片文件连接器是薯片生态中的**辅助工具**，专门解决批量绑定外部资源到卡片的问题。它是一个独立的小工具，可以集成到编辑引擎中使用，也可以作为独立窗口运行。

### 1.2 解决的问题

在薯片生态中，卡片可以引用外部资源（空壳卡片模式）。当用户有大量文件需要关联到对应卡片时，手动逐个绑定非常繁琐。文件连接器通过三种智能方式帮助用户快速完成批量绑定：

1. **手动连接**：直观的界面让用户快速建立绑定关系
2. **自动识别**：分析命名规律自动匹配
3. **智能识别**：AI语义分析处理复杂情况

### 1.3 产品边界

**包含的功能**：
- 批量绑定外部资源到卡片
- 三种连接模式（手动、自动、智能）
- 绑定预览和确认
- 资源模式批量转换（空壳↔全填充）

**不包含的功能**：
- 卡片编辑（由编辑引擎负责）
- 文件浏览和管理（由资源管理器负责）
- 卡片渲染和查看（由查看器负责）

## 2. 核心理念

### 2.1 三级智能化

```
手动连接        自动识别        智能识别
   │              │               │
   ▼              ▼               ▼
用户控制    →   规律匹配    →   语义理解
(最高准确)    (高效便捷)      (复杂场景)
```

三种模式各有适用场景，用户可以根据实际情况选择：
- **手动连接**：适合文件数量少、命名规律不明显的情况
- **自动识别**：适合文件命名有规律可循的情况
- **智能识别**：适合命名复杂、跨语言、语义关联的情况

### 2.2 预览确认原则

无论使用哪种连接模式，最终都需要用户确认绑定关系。系统展示完整的绑定预览，用户检查无误后再执行。这确保了：
- 用户对绑定结果有完全的控制权
- 避免误操作导致的数据损坏
- 支持在执行前进行微调

### 2.3 无损操作

绑定操作只修改卡片的配置文件（记录资源路径），不会移动或修改原始资源文件。用户可以随时重新绑定或解除绑定，不会造成数据丢失。

## 3. 目标用户

### 3.1 主要用户

| 用户类型 | 使用场景 | 需求特点 |
|---------|---------|---------|
| 内容创作者 | 批量关联视频、图片等资源 | 追求效率，希望快速完成 |
| 资料整理者 | 整理已有文件到卡片系统 | 文件数量大，需要自动匹配 |
| 内容分享者 | 准备分享内容时转换模式 | 需要批量转换资源模式 |

### 3.2 使用频率

文件连接器不是日常高频使用的工具。典型使用场景：
- 初次整理大量资源时
- 导入新一批资源时
- 准备分享卡片时

## 5. 产品原则

### 5.1 设计原则

1. **简单直观**：界面清晰，操作简单，降低学习成本
2. **高效批量**：针对批量操作优化，提高效率
3. **安全可控**：操作可预览、可撤销，用户有完全控制权
4. **灵活适应**：三种模式适应不同场景

### 5.2 技术原则

1. **通过内核通信**：所有模块间通信经过薯片内核
2. **多语言支持**：界面文本支持多语言切换
3. **主题适配**：支持深色/浅色主题
4. **配置化**：所有参数通过配置管理

## 6. 产品规格

### 6.1 支持的资源类型

| 资源类型 | 文件格式 | 对应卡片类型 |
|---------|---------|-------------|
| 视频 | mp4, mkv, avi, mov, webm | VideoCard |
| 音频 | mp3, wav, flac, aac, ogg | AudioCard |
| 图片 | jpg, png, gif, webp, svg | ImageCard |
| 文档 | pdf, docx, xlsx, pptx | 文档类卡片 |
| 字幕 | srt, ass, vtt | 字幕资源 |
| 其他 | 任意文件类型 | 通用资源 |

### 6.2 性能要求

| 指标 | 目标值 |
|------|-------|
| 启动时间 | < 1秒 |
| 自动匹配响应 | < 500ms (100个文件) |
| 智能识别响应 | < 3秒 (100个文件) |
| 批量绑定速度 | > 10个/秒 |
| 支持文件数量 | 1000+ |

### 6.3 兼容性

| 平台 | 支持状态 |
|------|---------|
| Windows 10+ | ✅ 完全支持 |
| macOS 11+ | ✅ 完全支持 |
| Linux (Ubuntu 20+) | ✅ 完全支持 |
