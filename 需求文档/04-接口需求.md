# 文件连接器 - 接口需求

**版本**: 1.0.0  
**更新时间**: 2026-02-01

---

## 1. 概述

### 1.1 接口分类

文件连接器的接口分为以下几类：

1. **内核通信接口** - 与薯片内核的通信
2. **SDK调用接口** - 使用SDK提供的API
3. **外部服务接口** - AI服务等外部依赖
4. **模块导出接口** - 对外提供的接口

### 1.2 通信原则

所有模块间通信必须通过薯片内核路由，不允许直接调用。

```
文件连接器 → Chips-core → 目标模块
```

## 2. 内核通信接口

### 2.1 请求卡片信息

**服务名**: `card.read`

**请求**:
```typescript
{
  service: 'card.read',
  payload: {
    card_id: string,
    include_content: boolean,
    include_resources: boolean
  }
}
```

**响应**:
```typescript
{
  status: 'success',
  data: {
    card: {
      id: string,
      metadata: CardMetadata,
      structure: CardStructure,
      resources: ResourceInfo[]
    }
  }
}
```

### 2.2 更新卡片配置

**服务名**: `card.update`

**请求**:
```typescript
{
  service: 'card.update',
  payload: {
    card_id: string,
    updates: {
      content?: Record<string, any>,
      metadata?: Partial<CardMetadata>
    }
  }
}
```

**响应**:
```typescript
{
  status: 'success',
  data: {
    success: boolean,
    modified_at: string
  }
}
```

### 2.3 读取资源

**服务名**: `resource.fetch`

**请求**:
```typescript
{
  service: 'resource.fetch',
  payload: {
    uri: string,  // chips://协议URI
    options?: {
      cache?: boolean,
      timeout?: number
    }
  }
}
```

**响应**:
```typescript
{
  status: 'success',
  data: {
    uri: string,
    content_type: string,
    size: number,
    data: ArrayBuffer | string
  }
}
```

### 2.4 写入资源

**服务名**: `resource.write`

**请求**:
```typescript
{
  service: 'resource.write',
  payload: {
    uri: string,
    data: ArrayBuffer | string,
    options?: {
      overwrite?: boolean,
      create_directories?: boolean
    }
  }
}
```

**响应**:
```typescript
{
  status: 'success',
  data: {
    success: boolean,
    path: string
  }
}
```

### 2.5 文件识别

**服务名**: `file.identify`

**请求**:
```typescript
{
  service: 'file.identify',
  payload: {
    file_path: string
  }
}
```

**响应**:
```typescript
{
  status: 'success',
  data: {
    file_type: string,
    extension: string,
    mime_type: string,
    valid: boolean
  }
}
```

### 2.6 列出文件

**服务名**: `file.list`

**请求**:
```typescript
{
  service: 'file.list',
  payload: {
    path: string,
    recursive?: boolean,
    filter?: {
      extensions?: string[],
      pattern?: string
    }
  }
}
```

**响应**:
```typescript
{
  status: 'success',
  data: {
    files: Array<{
      name: string,
      path: string,
      size: number,
      type: string,
      modified_at: string
    }>
  }
}
```

## 3. SDK调用接口

### 3.1 CardAPI

**加载卡片**:
```typescript
// 通过SDK加载卡片
const card = await sdk.card.get(cardId, {
  includeContent: true,
  includeResources: true
});
```

**更新卡片**:
```typescript
// 更新卡片内容配置
await sdk.card.update(cardId, {
  content: {
    [baseCardId]: {
      video_file: '/path/to/video.mp4'
    }
  }
});
```

### 3.2 FileAPI

**加载卡片文件**:
```typescript
// 直接加载卡片文件
const card = await sdk.file.loadCard('/path/to/card.card');
```

**保存卡片文件**:
```typescript
// 保存卡片到文件
await sdk.file.saveCard('/path/to/card.card', card, {
  overwrite: true
});
```

**验证卡片**:
```typescript
// 验证卡片格式
const result = sdk.file.validateCard(card);
if (!result.valid) {
  console.error(result.errors);
}
```

### 3.3 ResourceManager

**加载资源**:
```typescript
// 加载资源文件
const blob = await sdk.resources.load('/path/to/resource');
```

**创建对象URL**:
```typescript
// 创建预览URL
const url = await sdk.resources.createObjectUrl('/path/to/resource');
```

**获取资源信息**:
```typescript
// 获取资源元信息
const info = await sdk.resources.getInfo('/path/to/resource');
console.log(info.size, info.content_type);
```

## 4. AI服务接口

### 4.1 智能匹配接口

**请求URL**: `POST /api/v1/smart-match`

**请求头**:
```
Content-Type: application/json
Authorization: Bearer <token>
```

**请求体**:
```typescript
interface SmartMatchRequest {
  // 卡片列表
  cards: Array<{
    id: string;
    name: string;
    type?: string;
    description?: string;
  }>;
  
  // 文件列表
  files: Array<{
    path: string;
    name: string;
    size?: number;
    type?: string;
  }>;
  
  // 选项
  options?: {
    // 语言提示
    language?: 'auto' | 'zh' | 'en' | 'ja';
    // 上下文信息
    context?: string;
    // 最大匹配数
    max_matches?: number;
    // 最低置信度阈值
    min_confidence?: number;
  };
}
```

**响应体**:
```typescript
interface SmartMatchResponse {
  // 匹配结果
  matches: Array<{
    card_id: string;
    file_path: string;
    confidence: number;  // 0-100
    reason?: string;     // AI解释匹配原因
  }>;
  
  // 未匹配项
  unmatched: {
    cards: string[];     // 未匹配的卡片ID
    files: string[];     // 未匹配的文件路径
  };
  
  // 元信息
  metadata: {
    processing_time: number;  // 处理耗时(ms)
    model_version: string;    // 使用的模型版本
  };
}
```

**错误响应**:
```typescript
interface ErrorResponse {
  error: {
    code: string;
    message: string;
    details?: any;
  };
}
```

**错误码**:
| 错误码 | 说明 |
|--------|------|
| AI-001 | 请求格式错误 |
| AI-002 | 认证失败 |
| AI-003 | 配额超限 |
| AI-004 | 服务不可用 |
| AI-005 | 处理超时 |

### 4.2 AI服务配置

```typescript
interface AIServiceConfig {
  // 服务端点
  endpoint: string;
  
  // 认证令牌
  token: string;
  
  // 超时设置

  // 重试设置
  retry: {
    max_attempts: number;
    delay: number;
  };
  
  // 默认选项
  defaults: {
    language: string;
    min_confidence: number;
  };
}
```

## 5. 模块导出接口

### 5.1 FileConnector类

文件连接器对外提供的主要接口：

```typescript
export class FileConnector {
  /**
   * 初始化连接器
   * @param options 配置选项
   */
  constructor(options?: FileConnectorOptions);
  
  /**
   * 手动连接
   * @param bindings 绑定列表
   * @returns 执行结果
   */
  async manualConnect(bindings: BindingItem[]): Promise<ConnectResult>;
  
  /**
   * 自动识别匹配
   * @param cards 卡片列表
   * @param files 文件列表
   * @param mode 匹配模式
   * @returns 匹配方案列表
   */
  async autoMatch(
    cards: CardInfo[],
    files: FileInfo[],
    mode: MatchMode
  ): Promise<MatchScheme[]>;
  
  /**
   * 智能识别匹配
   * @param cards 卡片列表
   * @param files 文件列表
   * @returns 匹配结果
   */
  async smartMatch(
    cards: CardInfo[],
    files: FileInfo[]
  ): Promise<SmartMatchResult>;
  
  /**
   * 执行绑定
   * @param bindings 绑定列表
   * @param options 执行选项
   * @returns 执行结果
   */
  async executeBindings(
    bindings: BindingItem[],
    options?: ExecuteOptions
  ): Promise<ExecuteResult>;
  
  /**
   * 批量转换资源模式
   * @param cardIds 卡片ID列表
   * @param targetMode 目标模式
   * @param options 转换选项
   * @returns 转换结果
   */
  async batchConvert(
    cardIds: string[],
    targetMode: 'full' | 'empty',
    options?: ConvertOptions
  ): Promise<ConvertResult>;
  
  /**
   * 销毁连接器
   */
  destroy(): void;
}
```

### 5.2 类型定义

```typescript
// 配置选项
interface FileConnectorOptions {
  sdk: ChipsSDK;
  aiService?: AIServiceConfig;
  logger?: Logger;
}

// 绑定项
interface BindingItem {
  cardId: string;
  baseCardId?: string;
  resourceField: string;
  filePath: string;
}

// 卡片信息
interface CardInfo {
  id: string;
  name: string;
  type?: string;
  baseCards?: Array<{
    id: string;
    type: string;
    resourceFields: string[];
  }>;
}

// 文件信息
interface FileInfo {
  path: string;
  name: string;
  size: number;
  type: string;
  modifiedAt: string;
}

// 匹配模式
type MatchMode = 'number_sequence' | 'keyword' | 'file_order';

// 匹配方案
interface MatchScheme {
  mode: MatchMode;
  confidence: number;
  bindings: BindingItem[];
  unmatchedCards: string[];
  unmatchedFiles: string[];
}

// 智能匹配结果
interface SmartMatchResult {
  bindings: Array<BindingItem & { confidence: number; reason?: string }>;
  unmatchedCards: string[];
  unmatchedFiles: string[];
}

// 执行选项
interface ExecuteOptions {
  copyToInternal?: boolean;
  onProgress?: (current: number, total: number) => void;
  onError?: (error: Error, binding: BindingItem) => 'skip' | 'retry' | 'abort';
}

// 执行结果
interface ExecuteResult {
  success: number;
  failed: number;
  skipped: number;
  errors: Array<{ binding: BindingItem; error: Error }>;
}

// 转换选项
interface ConvertOptions {
  targetPath?: string;  // 空壳模式的资源目标路径
  resourceTypes?: string[];  // 要转换的资源类型
  onProgress?: (current: number, total: number) => void;
}

// 转换结果
interface ConvertResult {
  success: number;
  failed: number;
  totalSize: number;  // 转换的总大小（字节）
  errors: Array<{ cardId: string; error: Error }>;
}
```

### 5.3 事件

```typescript
// 连接器事件
interface FileConnectorEvents {
  // 绑定开始
  'binding:start': { total: number };
  
  // 绑定进度
  'binding:progress': { current: number; total: number; binding: BindingItem };
  
  // 单个绑定完成
  'binding:complete': { binding: BindingItem };
  
  // 单个绑定失败
  'binding:error': { binding: BindingItem; error: Error };
  
  // 所有绑定完成
  'binding:finish': { result: ExecuteResult };
  
  // 转换开始
  'convert:start': { cardIds: string[]; targetMode: string };
  
  // 转换进度
  'convert:progress': { current: number; total: number; cardId: string };
  
  // 转换完成
  'convert:finish': { result: ConvertResult };
}
```

## 7. 错误处理

### 7.1 错误码定义

| 错误码 | 分类 | 说明 |
|--------|------|------|
| FC-1001 | 输入 | 无效的卡片ID |
| FC-1002 | 输入 | 无效的文件路径 |
| FC-1003 | 输入 | 绑定列表为空 |
| FC-2001 | 文件 | 文件不存在 |
| FC-2002 | 文件 | 文件无法读取 |
| FC-2003 | 文件 | 文件类型不支持 |
| FC-3001 | 卡片 | 卡片不存在 |
| FC-3002 | 卡片 | 卡片无法写入 |
| FC-3003 | 卡片 | 卡片格式错误 |
| FC-4001 | 网络 | AI服务不可用 |
| FC-4002 | 网络 | 请求超时 |
| FC-5001 | 系统 | 磁盘空间不足 |
| FC-5002 | 系统 | 内存不足 |

### 7.2 错误处理策略

```typescript
// 错误处理函数类型
type ErrorHandler = (
  error: FileConnectorError,
  context: {
    operation: string;
    binding?: BindingItem;
    cardId?: string;
  }
) => 'skip' | 'retry' | 'abort';

// 默认错误处理
const defaultErrorHandler: ErrorHandler = (error, context) => {
  switch (error.code.substring(0, 4)) {
    case 'FC-1':  // 输入错误
      return 'abort';  // 终止操作
    case 'FC-2':  // 文件错误
      return 'skip';   // 跳过当前
    case 'FC-3':  // 卡片错误
      return 'skip';   // 跳过当前
    case 'FC-4':  // 网络错误
      return 'retry';  // 重试
    case 'FC-5':  // 系统错误
      return 'abort';  // 终止操作
    default:
      return 'skip';
  }
};
```
