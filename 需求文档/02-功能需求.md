## 2. 手动连接模块

### 2.1 表格界面 🔴

**功能描述**：
提供传统的列表形式界面，左列显示卡片列表，右列显示文件选择，用户可以逐行建立绑定关系。

**功能要求**：

| 编号 | 功能点 | 优先级 | 描述 |
|------|--------|--------|------|
| MC-T-001 | 卡片列表展示 | 🔴 | 显示需要绑定资源的卡片列表，包括卡片名称、当前资源状态 |
| MC-T-002 | 文件选择按钮 | 🔴 | 每行提供文件选择按钮，点击打开文件选择对话框 |
| MC-T-003 | 拖拽绑定 | 🔴 | 支持将文件拖拽到对应行完成绑定 |
| MC-T-004 | 批量文件夹设置 | 🟡 | 选中多行后，可以批量设置同一个文件夹作为来源 |
| MC-T-005 | 排序功能 | 🟡 | 支持按卡片名称、状态等排序 |
| MC-T-006 | 筛选功能 | 🟢 | 筛选已绑定/未绑定的卡片 |
| MC-T-007 | 预览文件 | 🟢 | 点击已绑定的文件可以预览 |

**界面布局**：
```
┌────────────────────────────────────────────────────┐
│  工具栏: [选择文件夹] [清空] [自动填充] [导入]      │
├──────────────────────┬─────────────────────────────┤
│      卡片列表        │         文件绑定            │
├──────────────────────┼─────────────────────────────┤
│ ☐ 第01集             │ [选择文件...] EP01.mp4 ✓   │
│ ☐ 第02集             │ [选择文件...] (未绑定)     │
│ ☐ 第03集             │ [选择文件...] EP03.mp4 ✓   │
│ ...                  │ ...                        │
├──────────────────────┴─────────────────────────────┤
│  状态栏: 已绑定 8/10                               │
└────────────────────────────────────────────────────┘
```

**交互流程**：
1. 用户打开文件连接器，选择需要绑定的卡片
2. 卡片列表加载并展示
3. 用户点击某行的文件选择按钮或拖拽文件
4. 选择/拖拽文件完成单个绑定
5. 重复操作直到所有卡片绑定完成

## 3. 自动识别模块

### 3.1 数字序列匹配 🔴

**功能描述**：
提取卡片名称和文件名称中的数字，按数字对应关系自动匹配。

**功能要求**：

| 编号 | 功能点 | 优先级 | 描述 |
|------|--------|--------|------|
| AR-N-001 | 数字提取 | 🔴 | 从字符串中提取所有数字序列 |
| AR-N-002 | 数字匹配 | 🔴 | 按数字值进行匹配（01=1=001） |
| AR-N-003 | 多数字处理 | 🟡 | 处理包含多个数字的情况 |
| AR-N-004 | 匹配配置 | 🟡 | 配置使用哪个位置的数字 |

**匹配示例**：
```
卡片名称           文件名称           匹配结果
─────────────────────────────────────────────
"第01集"           "EP01.mp4"         ✓ 匹配 (01=01)
"第2集"            "episode_002.mkv"  ✓ 匹配 (2=002)
"Season1-EP03"     "S1E03.mp4"        ✓ 匹配 (多数字匹配)
```

## 4. 智能识别模块

### 4.1 AI语义分析 🔴

**功能描述**：
使用人工智能接口分析卡片名称和文件名称的语义关系，处理复杂的命名情况。

**功能要求**：

| 编号 | 功能点 | 优先级 | 描述 |
|------|--------|--------|------|
| AI-001 | 文本准备 | 🔴 | 将卡片列表和文件列表整理为AI输入 |
| AI-002 | 接口调用 | 🔴 | 调用AI服务进行分析 |
| AI-003 | 结果解析 | 🔴 | 解析AI返回的匹配建议 |
| AI-004 | 置信度分级 | 🔴 | 按置信度分为高/中/低三级 |
| AI-005 | 跨语言识别 | 🟡 | 支持不同语言之间的匹配 |
| AI-006 | 模型配置 | 🟡 | 配置使用的AI模型 |
| AI-007 | 离线降级 | 🟢 | AI服务不可用时降级到自动识别 |

**置信度分级**：
```
高置信度 (>80%)  → 直接显示为确定匹配
中置信度 (50-80%) → 显示为建议匹配，需要确认
低置信度 (<50%)  → 显示为可能匹配，建议手动确认
```

**AI接口规范**：
```typescript
// 请求格式
interface AIMatchRequest {
  cards: Array<{ id: string; name: string }>;
  files: Array<{ path: string; name: string }>;
  options?: {
    language?: string;
    context?: string;
  };
}

// 响应格式
interface AIMatchResponse {
  matches: Array<{
    cardId: string;
    filePath: string;
    confidence: number;  // 0-100
    reason?: string;
  }>;
  unmatched: {
    cards: string[];
    files: string[];
  };
}
```
